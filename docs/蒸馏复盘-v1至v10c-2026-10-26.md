# 游戏舆情情感蒸馏复盘：v1 → v10c

> 整理日期：2026-10-26  
> 用途：把微调、蒸馏、评估尺子和工作点上的坑收成一份，后面复盘不用再翻散落笔记。  
> 数字来源：`docs/student模型v1-v6训练经验总结-2026-09-12.md`、`docs/游戏舆情情感模型优化报告-2026-09-11.md`、`docs/数据集对齐配置.md`、`docs/v9训练方案-gold_eval_v6-2026-09-15.md`、`docs/student模型v9o之后-v10训练经验总结-2026-09-20.md`、`docs/v9j误差解剖-B站护栏-2026-09-18.md`。原文有冲突时，以文内注明的评估集为准。  
> **现役：`student_v8` + 平台/内容类型前缀 + 非对称回退（`conf<0.75` 且预测不是负面 → 改判中性）。v9 / v10 一律未部署。**

## 0. 先看结论

这条链路不是「大模型上线打标」，而是 **GLM（及早期方案里的双教师）只负责造训练标签，线上跑 110M 的 Erlangshen-Roberta 学生模型**。标签是三分类：负面 / 中性 / 正面。序列长度 256。

走完 v1 到 v10c，能留下的判断是：

1. **先验对齐比加数据值钱。** v2 数据翻倍反而掉分；v6 域内放量把安全网撑破。
2. **学生模型看不见平台时，平台相反的口径会互相污染。** v7 证实了这一点，v8 用输入前缀拆开，这是唯一真正晋级的机制改动。
3. **低置信回退是工作点，不是模型能力。** 它在 B站玩梗上很赚，在微博评论的真负面上会亏。v5 的一刀切回退后来被 v8 的「负面豁免」接替。
4. **充分训练会把置信度顶上去，回退垫子变薄。** v5 实际是 1 epoch 欠训练，宽置信带和 T=0.75 是一起长出来的。后面充分训练的模型不能靠同一张网。
5. **坏尺子会选出最差的模型。** gold_v6 的 B站片 91.5% 是中性，「准确率不低于 v8」在结构上惩罚任何提升负面召回的配方。v9o 因此假阳性过闸，i.i.d. 抽检把它否决。
6. **现役停在 v8。** 之后的 v9 扫参和 v10 去重 / 回放 / 小剂量中性校准，都没有同时保住微博两片、B站护栏和挑战集负召回，也没有通过 i.i.d.。

## 1. 方法骨架

```
存量/数仓抽样 → teacher 分片标注（只保留可校验的 jsonl）
    → 与上一版混训（金标永不进训练）
    → 学生模型从上一版或底座继续微调
    → 在冻结的金标 + 同一工作点上过闸
    → 不过就维持现役；低置信样本回到候选池
```

教师侧落地主要是 GLM 分片标注（说明书在 `prompts/glm_teacher_shard*.md`），合并时校验 id 集合和 text 逐字节一致。v7.1 另用 Claude 对 round4 的 600 行做了纯标签质量消融。早期方案写过 Qwen 与 DeepSeek 交叉，只保留两者一致的样本；后面轮次的笔记以 GLM 分片为准。

学生侧底座是 `IDEA-CCNL/Erlangshen-Roberta-110M-Sentiment`。生产推理不调用教师模型。

部署侧有两个工作点，不要混称「模型变好了」：

| 工作点 | 规则 | 主要使用阶段 |
|---|---|---|
| 一刀切回退 T=0.75 | softmax 最高概率 < 0.75 一律改判中性 | v5 现役期 |
| 非对称回退 `neg_exempt` | 同样阈值，但**预测为负面的不改** | v8 起现役 |

原始预测留在 `raw_sentiment`，供审计和回流。

## 2. 读数字之前：尺子换过四次

不同金标上的准确率**不能横比**。v1 的 0.80 和 v8 的 0.85 不是同一件事。

| 评估集 | 规模 | 用来裁决谁 | 结构特点 |
|---|---|---|---|
| 早期金标 | 401 | v1–v3 | 博文为主 |
| gold_eval_v4 | 557 | v4–v6 | 第一次三片统一留出 |
| gold_eval_v5 | 857 | v5 后期、v8 晋级数字 | 中性 76.9%，回退到中性容易显得赚 |
| gold_eval_v6 | 1296 | v9 全系列 | 评论扩到 505；中性降到 69.9%。B站片仍是 390 条里 357 条中性 |
| gold_eval_v7 + challenge | 1595 + 250 | v9 重判、v10 | B站 iid 扩样并进主集；250 条负面富集集**不进主集**，专门量负召回 |

同一份 v8 权重可以说明尺子的影响：`neg_exempt` 在 gold_v5 上是 **0.8495**，在 gold_v6 上是 **0.8218**。前 857 行仍是 0.8495，掉下去的 2.8pt 全来自新评论片，不是模型退步。

i.i.d. 抽检（真实流量、不按模型分数富集）从 v8 晋级讨论起就是否决权。gold 过闸只是入场券。

## 3. 逐版：问题、做法、结果

### v1 — 冷启动基线

- **数据：** round1，3000 条，微博主池分层。
- **结果：** 401 条早期金标准确率 **0.7955**。可用，作为后面所有「加数据是否真的更好」的对照。
- **留下的方法：** 分片标注、id + text 校验、学生模型不看教师的理由字段。

### v2 — 主动学习把先验采歪了

- **问题：** round2 用 70% 难例配额（低置信，或判中性且负面概率 ≥ 0.2），采出负面占比 **44.7%**，真实流量大约 21%。难例里的锐评、阴阳、玩梗在当时口径下大量被标成负面。
- **叠加的标注错误：** prompt 写了「应援 → 正面」，224 条点赞 / 打 call 仪式评论被标成正面。学生把仪式应援也学成正面。
- **结果：** 训练数据变多，早期金标准确率 **0.7955 → 0.7880**。笔记里真实任务从约 84% 掉到约 79%。蒸馏数据翻倍，效果反降。
- **结论：** 难例挖掘会富集边界样本；边界样本的标签分布不是线上分布。直接混训等于教一个假的「负面很多」。

### v3 — 把负面先验拉回来

- **方法：** 难例配额降到 30%，并且只收 `conf<0.6`，删掉「按负面概率捞负面」。70% 改为平台分层随机。标完若负面超过 26% 就降采样再混训。另立规则：拿不准判中性。224 条仪式应援改回中性；26 条没有明确批评对象的伤感语录改回中性，励志语录不动——批量翻标签必须限制在无歧义子类。
- **结果：** 降采样后约 4508–4869 条（两份笔记口径略有出入），早期金标 **0.8080**。相对 v2 大约 +2pt。负面先验对齐是这一阶段最大的杠杆。
- **工程坑：** 用 8 位 id 前缀改标签，曾经误翻 262 条。此后改标签必须用完整 id。

### v4 / v4b — 换统一留出集，过采样补最弱片

- **问题：** 旧金标只有 401 条，B站片太薄，版本之间不可比。v4 起改用 gold_eval_v4（557）。换尺子之后总分看起来下降，这是尺子变了，不是模型突然变差。
- **v4：** 在 v3 基底上并入人工新标注 361 条。gold_v4 **0.7343**。B站仍是最弱片。
- **v4b：** B站 ×3、微博评论 ×2 过采样，5438 条。gold_v4 **0.7487**。过采样有效，但是上一代里的局部最优，三片仍不均衡（博文 0.8279 / B站 0.5778 / 微博评论 0.5000）。
- **方法：** 从此版本对比固定为三件事：三片准确率、配对差异（只 A 对 / 只 B 对）、阈值扫描。禁止拿总准确率一句话宣布晋级。

### v5 — 小步试标 + 回退，第一次可部署

- **问题：** 试标 300 条里微博博文只有 8 条、评论 142 条。评论的「直球夸赞 → 正面」泄漏到博文仪式应援，博文 raw 掉约 2.7pt。错误集中在低置信区。
- **方法：** 放量配额按片锁死：B站评论 40% / 微博评论 30% / 微博博文 30%，候选行必须带 `content_type`。先用 300 条试标闭环（修正后负面 17.3%），再决定是否放量。部署加上 T=0.75 一刀切回退：低置信样本大约 76% 金标为中性，改判中性，原判保留。
- **数据：** v4b 5438 + 试标 300 = 5738，负面 23.0%。**没有把后来否决的 round3 放量 1000 条训进去**（那是 v6）。
- **结果（gold_v4，557）：** raw **0.7576**，加回退 **0.8133**。相对 v4b 回退版 +2.7pt，B站 +11.1pt（0.7111 → 0.8222），三片都更好。回退本身 +5.6pt，正面召回不降。
- **另一把尺子：** 数据集对齐表把 v5 的晋级数字记在 gold_v5 回退 **0.8343**。和 0.8133 不是同一评估集。
- **代价：** 真实 200 条抽检里，负面召回从 raw 11/20 掉到回退后 6/20。微博评论 50 条里回退翻错 4 条真负面、只翻对 1 条。收益集中在 B站。
- **回退盖不住的错误：** 高置信漏判。直球加油判中性（置信 0.92 以上），黑话反讽判正面（「缅北赛蛆」一类，置信可以到 0.95）。这类只能补样本，不能靠阈值。
- **事后审计（2026-09-15）：** 当时的 v5 是 **1 epoch 欠训练**。宽置信带和 T=0.75 是共适应的拐杖。后面任何「训得更充分」的模型都会更自信，同一张网会失灵。这解释了 v6 以及再往后好几轮「数据变多、低置信样本变少、回退保护变薄」。

真实抽检（教师复核，不是金标）：400 条里 B站按项目口径约 92.5%；另 200 条全新样本 raw 0.81 / 回退后 0.85。外部 agent 标注和项目人工口径一致率约 82%，agent 把玩梗大量标成负面，模型更接近金标而不是那个 agent。

### v6 — 单域放量，安全网被自信撑破

- **做法：** 把 round3 放量的 1000 条（全是 LoL 赛事域）混进 v5，6738 条。
- **问题：** 金标是多游戏（异环、鸣潮等）。域内放量不带来跨域收益，B站中性短句更多被判成正面。同时 `max_prob<0.75` 的样本从 149 条降到 60 条，回退垫子缩水，raw 错误直接出去。
- **结果（gold_v4）：** 回退后 **0.7756**，低于 v5 的 0.8097（笔记里 v5 对照点与 0.8133 的差来自对照口径，方向一致：全区间 T∈[0.6, 0.9] 都不如 v5）。配对净负 19，三片都败。**否决。**
- **教训：** 「再加 1000 条同类数据」在这条链上不成立。下一轮必须多游戏，而且要单独看置信度分布，不能只看训练 loss。

### v7 / v7b / v7.1 — 补对了样本，缺的是平台条件

- **v7：** v5 + round4 训练片 1157（多游戏微博 + B站定向难例 171），6895 条。目标是修 v6 的域偏移，并补两类高置信洞：直球应援判中性、黑话反讽判正面。**不晋级。** 失败模式是 B站跨域干扰：微博问责黑话（负面）和 B站玩梗（中性）文本像，单模型只能看字，口径相反的监督互相抵消。
- **v7b：** 消融，只用 round4 的纯微博 986 条，6724 条。仍不晋级，但博文片反超 v5。说明 round4 的微博部分不是废物，B站难例混进去才是干扰源。
- **v7.1：** 行集与 v7 相同，按 id 把 600 行换成 Claude 重标（与 GLM 一致率 84%，分歧主要是 GLM 的极性被 Claude 改成中性）。负面占比 21.6%。相对 v7 净 −2 条，相对 v5 仍是 v7 那种失败。**标签质量不是瓶颈。**
- **数据卫生：** round4 留出 200 条（seed 46）不进训练，用来验阈值。金标与训练文本要做排除，避免泄漏。

这一阶段把「继续堆通用文本」证伪了。笔记里的架构结论是：要么给输入加平台特征，要么分平台模型。v8 走了前一条，因为线上仍要一个模型吃多平台。

### v8 / v8b — 前缀把平台条件写进输入，现役由此产生

- **唯一变量：** 语料、超参、初始化与 v7.1 相同。只改输入。`platform_input.py` 在正文前拼接受限前缀，禁止自由发挥：
  - `[微博博文] `、`[微博评论] `、`[B站评论] `
  - 缺字段、小红书或未支持组合 → `[未知] `
  - 目录名版本号 ≥ 8 时推理自动打开前缀，旧模型保持原文，历史数字可复现。
- **机制结果：** B站跨域干扰清掉。独立 holdout **0.6950**，当时最高。对称回退 T=0.75 的总准确率 0.8355 达标，但三片里只有 B站不劣于对照，**按「三片都不差」不能晋级**。博文负面先验变软。
- **v8b：** 前缀降成只区分平台（`[微博]` / `[B站]`），不再区分博文和评论。总准确率 0.8320。博文负召回 raw 与 v8 同为 0.882，所以「负面变软」不是因为前缀太细。去掉内容类型之后，B站和 holdout 变差。内容类型前缀留着。
- **晋级工作点（2026-09-15）：** 一刀切回退会打掉低置信真负面（博文上 28/85 这类损失被记成「博文变差」，其中一部分是工作点假象：博文 raw 0.8130 已经高于 v5 的 0.7980）。改成负面豁免后，在 **gold_v5** 上总准确率 **0.8495**、博文 0.8304、B站 0.9179、负召回 0.882、macro F1 0.7339。holdout 0.6650，高于 v5 的任意工作点。当天决定现役切到 **v8 + 前缀 + neg_exempt**。raw 和豁免的最后取舍留给 i.i.d.，切换只是一个开关。
- **换到 gold_v6 之后的同一权重：** 总准确率 0.8218。分片：B站 0.9179（正召回 0.25、负召回 0.24，片内几乎全是中性）、博文 0.8304（负召回 0.88）、微博评论 **0.7406**。评论片上 raw 0.7644 优于豁免 0.7406：全局豁免在评论片净伤害，在博文和 B站仍更好。
- **试过但没上线：** 微博评论走 raw、其余片走豁免。gold_v6 总准确率 **0.8310**（评论 0.7644）。代码在 `infer_batch.py --weibo_comment_raw`，默认关。

i.i.d. 300 条抽检结案时，v8+豁免仍是当时最优（准确率 **0.8667**）。这是后面否决 v9o / v9k 的锚。

### v9 家族 — 用 round6 补评论短板，扫参扫到一把坏尺子

round6：1200 条，多游戏，不是纯 LoL。微博评论 531（其中应援类 339）、博文 316、B站 353（抗议类 279）。负面 22.8%，落在 21–26%，不用再降采样。与当时金标文本零重合。混进 v7.1 后是 `v9_train_mixed.jsonl`，8095 条。明确不把金标、不再纯 LoL、不把另一条品牌舆情域塞进游戏模型。

v9 本体（全量 round6，学习率约 2e-5，从 v8 初始化）在 gold_v6、`neg_exempt` 上：

| 片 | v9 | v8 | Δ |
|---|---|---|---|
| 总体 | 0.8233 | 0.8218 | +0.15pt |
| 微博评论 | 0.7545 | 0.7406 | +1.4pt |
| 微博博文 | 0.8454 | 0.8304 | +1.5pt，负召回 0.94 |
| B站 | 0.8897 | 0.9179 | **−2.8pt，闸门失败** |

评论和博文的方向是对的，B站被全量重训和 round6 的抗议域一起打下来。**未晋级。**

后面 v9b–v9o 是同一目标上的消融，不是一串独立产品。对照都是相对 v8 在 gold_v6 上的点数：

| 版本 | 改了什么 | 评论 | 博文 | B站 | 闸门 |
|---|---|---|---|---|---|

| v9c | 只混 round6 微博，全量重训 | +1.8 | −0.5 | −2.8 | FAIL |
| v9d | 只增量微博，1e-5 × 2 epoch | +1.4 | −4.2 | +0.3 | FAIL，博文崩 |
| v9e | 只增量微博评论 | 数字在对应 baseline json | | | |
| v9f | 评论增量 + 1× 博文回放 | +2.0 | −1.75 | 0 | FAIL |
| v9h | 评论增量 + 2× 博文回放 | +1.6 | −1.0 | −0.25 | FAIL |
| v9i | 全量 round6，1e-5 × 2 | +1.6 | +1.0 | −2.05 | FAIL |

| v9k | v9j 后再用 v7.1 的 B站回放 1 epoch | +2.2 | +0.25 | −0.51 | FAIL，大约还差 2 条 |

v9o 的绝对数：总 0.8318，评论 0.7604，博文 0.8329（负召回 0.918），B站 0.9231。配方是「先不看 round6 的 B站抗议，再用很软的学习率短回放旧 B站」。更强、更长的回放（v9l、v9n）会过拟合退回去。

**v9o 不晋级。** gold 过了，i.i.d. 退步：

| 验证 | v9o | v8 |
|---|---|---|
| 已有抽检 300 | 0.8567 | **0.8667**（头对头独对 1:4） |
| 新抽 487 的分歧 | 胜 4 | **胜 6**（10 条里） |
| B站负召回（当时金标 B站负例约 17） | 3/17 | 4/17 |

闸门选出了全系列里 B站负召回最差的模型。v9b 负召回最高（7/17），B站准确率最低，被闸门杀掉。原因是结构性的：B站片「全判中性」就有 **0.9154**，v8 的 0.9179 只多对 **1 条**。任何真正多抓负面的模型都会在 357 条中性上制造假阳性，片准确率必掉，于是「B站准确率 ≥ v8」禁止负面能力变好。

为了过这道闸，v9o 整段训练都没用 round6 B站里的 **191 条抗议负面**。

另外一条数据事实，比学习率更能解释 B站中性偏置：`v7_1_train_mixed.jsonl` 有 **569 行整行复制**，都来自 LoL。B站训练片 945 行里只有 529 个唯一文本，208 条中性闲聊各出现 3 次。v9o 的第二段回放集就是这 945 行，等于再曝光一遍。去重没有当成既定修复，因为现役 v8 就是在这份有复制的数据上训出来的。

### 修尺子，然后用新尺子重判存量

先扩评估，再训练。B站扩样禁止用模型分数做富集，否则尺子偏袒旧模型。

- gold_v7：gold_v6 的 1296 + B站随机扩样 299 = **1595**。B站评论 689（负面只有 31）、博文 401、微博评论 505。
- `gold_bili_neg_challenge.jsonl`：**250**，独立，不并进主集。中 178 / 负 69 / 正 3。只看负召回和负面精确率，准确率不许拿去和 iid 比。v8 基线负召回 **0.464**、负面精确率 **0.571**。抗议/动员通道里人工负面约 28%，v8 只判出约 15%，盲区被定量钉住。

`GATES_V7`（`gold_gates.py`）五条：微博评论和博文准确率不低于 v8；博文负召回 ≥ 0.88；B站准确率降为护栏（不低于 v8 减 1.0pt）；挑战集负召回不低于 v8；**i.i.d. 改为晋级必过**。

16 个已有 v9 checkpoint 用新尺子重跑，比再训便宜。只有 **v9k** 过了 gold 闸门：挑战集负召回大约只比 v8 多 3 条（0.507 vs 0.464），没补上抗议盲区。v9o 在新尺子上失败，挑战集负召回 **0.391**，比 v8 还低 7.2pt。v9j 最接近：挑战集负召回 **0.638**（+17.4pt），B站护栏大约还差 0.45pt（689 条里约 3 条）。

v9k 的 i.i.d. 仍失败：抽检 300 总准确率 0.8600 < v8 的 0.8667；B站负召回 2/12 < 3/12；另一批 487 的分歧头对头 v8 胜 9、v9k 胜 2。漏判包括把明确贬损收成中性。**gold PASS 不能上线。**

### v10a / v10b / v10c — 杠杆都切在「更负」或「剂量不够」

对照是 gold_v7 上相对 v8 的点数，外加挑战集负召回。v8 的挑战集负召回是 0.464。

| 版本 | 做法 | 评论 Δ | 博文 Δ | B站 Δ | 挑战集负召回 | 闸门 |
|---|---|---|---|---|---|---|
| v9j（对照，未去重） | 全量 round6，5e-6 × 2 | +2.0 | +0.2 | −1.5 | 0.638 | FAIL |
| v10a | 同一语料去掉 569 行复制，7526 条，5e-6 × 2，从 v8 起 | +1.2 | −0.3 | −2.8 | 0.652 | FAIL |
| v10b | v10a 再加 1× 博文回放 | +0.4 | −0.3 | −4.1 | **0.739** | FAIL |
| v10c | v9 底料 8095 + 219 条中性难例校准，8314 条，5e-6 × 2 | +1.8 | −0.5 | −1.5 | 0.580 | FAIL |

v10a 看起来像数据清洗。去重后 B站片从 1298 行降到 882 个唯一文本，负面占比 19.6% → **26.1%**。相对带复制的 v9j，挑战集负召回只再多约 1 条，B站护栏多摔约 1.3pt，博文从刚过线变成刚不过（−0.25pt）。删掉的复制行大多是中性，它们本来是护栏的沙袋。

v10b 把博文掉分理解成「忘了博文」，再回放博文。博文仍是 −0.25pt。挑战集负召回冲到 0.739，B站 −4.1pt。掉分是负面敏感度整体上移的连带损伤，不是缺博文曝光。再堆回放只会沿「更负」滑。

v10c 方向改成补中性，剂量是 219 条（重标后中 161 / 负 43 / 正 15）。B站护栏 **0.8708**，和 v9j 相同，仍低于 v8 约 1.45pt。挑战集负召回 0.580，反而低于 v9j 的 0.638。219 条撬不动大约 3 条护栏差额。

v9j 相对 v8 在 gold 的 B站片净少对 10 条（回归 19、改进 9）。回归不是随机噪声，是三条设计链：

1. **教师口径和后来的金标扩样打架。** round6 把 B站短应援 / 打 call 标成正面；金标扩样里大量「萌 / 惊艳」仍是中性。模型稳定交「中性 → 正面」的税（11 条）。
2. **抗议词表只推召回，没有同词的中性对照。** 电竞闲聊、玩梗、交易黑话被打成负面（8 条）。挑战集能救回 12 条真负面，仍有 25 条两边都漏（退游叙事、差一点意思、陈述式问责），另外新增 14 条假阳性，脏在抗议词的中性用法。
3. **去重拆掉的正是这些中性对照。** 所以 v10a 会把护栏打得更低。

这三件事改学习率或阈值都解不了。

## 4. 反复出现的机制

| 机制 | 第一次显形 | 后来又出现在 |
|---|---|---|
| 难例采样改变标签先验 | v2，负面 44.7% | v10a 去重把 B站负面从 19.6% 抬到 26.1%，只是方向反了 |
| 平台相反口径互相污染 | v3 试标、v7 | 没前缀之前加数据不会消失；v8 用前缀拆开 |
| 训练更充分 → 更自信 → 回退失效 | v6，低置信 149→60 | v5 欠训练审计；充分训练的 v9 不能再靠 v5 那张网 |
| 在评估集上把阈值调到更好看 | v5 在 T=0.85/0.90 更高 | 规定阈值只能用新的 i.i.d. 留出集定，不能在 gold 上扫 |
| 总准确率掩盖分片失败 | v4 的 B站 0.58 | v9 总准确率几乎不掉，B站 −2.8pt |
| 坏片准确率选出相反的模型 | v9o | 修成 gold_v7 之后，v9k 仍是 gold 过、i.i.d. 不过 |
| 为过闸删掉难片 | v9o 不用 191 条 B站抗议 | 和「把难的评测题拿掉」是同一类错误 |
| 教师和金标不是同一把尺子 | 仪式应援、伤感语录 | v9j 的轻度夸：训练当正面，扩样金标当中性 |

## 5. 现役配方（复盘时不要和实验模型混）

- **权重：** `student_v8`。公开权重在 `bruceant/game-sentiment-student-v8`。仓库不提交 `models/`。
- **输入：** 版本号 ≥ 8 自动加 `platform_ct` 前缀。推理漏前缀等于换了一套分布。
- **工作点：** `NEG_EXEMPT=1`，阈值 0.75。批量入口 `infer_batch.py --neg_exempt`。
- **训练底稿：** `v7_1_train_mixed.jsonl`，6895 行，含后来发现的 569 行复制。不要把「去重后的 v10a」说成现役数据。
- **晋级尺子：** `evaluate_gold_v7_gates.py` + i.i.d.。`GATES_V6` 只留着复现 v9，不能再当上线标准。
- **回退开关：** `WEIBO_COMMENT_RAW` 默认 0。gold_v6 上把它打开能到 0.8310，没有部署。
- **明确不再做（到 v10c 为止已被证伪）：** 再扫一遍 v9 已经走过的学习率和 epoch；把 B站或博文回放做得更长更猛；为了过某一片闸门整片删训练数据；继续「去重 + 全量负面」；把金标灌进 `train_student.py`；用模型分数去富集下一把金标。

## 6. 若还要动现役，下一刀切在哪

笔记停在这里，没有新的晋级模型：

1. 先统一「轻度夸 / 短应援」在教师和金标里的口径，否则中性→正面的税会一直交。
2. 中性校准要加量，并且对准三类：电竞闲聊、抗议词的中性用法（举报 / 跑路 / 垃圾）、已经统一口径的轻度夸。v10c 证明「加一点中性」不够。
3. 挑战集可以再扩，但富集仍然不能用模型分数。主集准确率和挑战集召回必须一起看。
4. 任何候选在 gold_v7 过闸之后，仍要用新的 i.i.d. 对 v8（0.8667 那批评注）做头对头。不过就维持 v8。

## 7. 复盘时建议沿用的纪律

1. 报准确率必须带评估集名字和工作点名字。不写「v8 是 0.85」这种脱上下文的句子。
2. 晋级看三片（或 v7 闸门的五条）加配对差异，不看总准确率单点。
3. 新金标并入前做 id / 文本重合检查，然后把这批 id 写进下一轮排除集。金标永不进训练。
4. 改标签用完整 id。合并教师结果时，行数、顺序、text 逐字节一致，否则整片重做。
5. 闸门只改 `gold_gates.py` 和它的单测，不在一次性脚本里各写各的比较。
6. 一个实验只动一个变量。v8 能解释，是因为它和 v7.1 只差前缀；v10b 解释起来痛苦，是因为去重和回放叠在一起。
7. 权重、原始评论和密钥不进 git。分发用 `share_student.py` 或已上传的 Hugging Face 仓库。
