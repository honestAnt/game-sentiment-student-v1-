# 游戏舆情情感模型优化报告

> 更新日期：2026-09-11 ｜ 现役版本：student_v5 + 置信回退 T=0.75

## 一、背景与方案

**任务**：游戏舆情情感三分类（正面 / 负面 / 中性），日处理 60–200 万条评论/博文。

**技术路线**：大模型蒸馏 —— GLM 当 teacher 逐条标注（含情绪标签与理由），蒸馏训练轻量 student 模型（二郎神 Roberta-110M-Sentiment，纯文本输入），生产环境 GPU 批量推理。低置信度样本自动回流为下一轮标注候选，形成「生产推理 → 挖掘难例 → 大模型标注 → 重新训练」的持续迭代闭环。

**本轮迭代范围**：三轮主动学习（round1 基线 3000 条 → round2 难例 2000 条 → round3 试标 300 + 放量 1000 条），模型从 v1 迭代至 v6。

## 二、本轮做了哪些优化

### 1. 标注口径修正（分平台）
- 确立最高优先级规则「**拿不准判中性**」，压制蒸馏标签噪声；
- **仪式化应援 → 中性**：修正 round2 的 224 条应援类误标（此前把点赞/打call仪式一律判正面，导致先验漂移）；
- **平台条件口径**（学生模型无平台输入，靠文体特征学习）：
  - B站评论：玩梗 / 阴阳 / 锐评 / 分析 → 中性；直球应援 / 直球夸赞 → 正面；黑称贬损 / 骂战 → 负面；
  - weibo 博文：官方战报 / 赛程 / 喜报 / 活动宣传 → 中性；
  - weibo 评论：直球夸 / 祝贺 / 加油 → 正面；实质批评 / 骂战 → 负面；
- 伤感语录（无明确批评对象）→ 中性。

### 2. 采样策略修正
- round2 用 70% 难例配额，采出**负面占比 44.7%**（真实分布约 21%），导致 v2 任务准确率 84% → 79%（先验漂移）；
- round3 改为：平台分层随机 70% + 低置信难例 30%（仅 conf<0.6），并增加**负面 >26% 自动降采样**；
- 修正后先验回归健康区间（试标 17.3%，放量 11.9%）；
- 采样配额按 (platform, content_type) 三分：B站评论 40% / weibo评论 30% / weibo博文 30%，修复「评论口径信号泄漏到博文」的跨口径泄漏问题。

### 3. 部署层置信回退（重要收益）
- `infer_batch.py --conf_threshold 0.75`：softmax 最高概率 < 0.75 的样本改判**中性**（金标验证低置信样本约 76% 为中性），原始判定保留在 raw_sentiment 列供审计；
- 低置信样本同时进入候选池，滚动送大模型标注。

### 4. 评估体系加固
- 人工金标扩容至 918 条（覆盖三片：博文 / weibo评论 / B站评论）；
- 新建留出评估集 gold_eval_v4（557 条，训练未见），所有版本统一口径对比。

## 三、取得了哪些提升

### 1. 金标留出集（gold_eval_v4，557 条）

| 版本 | 总体 | weibo博文 | B站评论 | weibo评论 |
|---|---|---|---|---|
| v4b（上一代最优） | 0.7487 | 0.8279 | 0.5778 | 0.5000 |
| v4b + T0.75 回退 | 0.7864 | 0.8329 | 0.7111 | 0.6061 |
| v5 raw | 0.7576 | 0.8005 | 0.6889 | 0.5909 |
| **v5 + T0.75 回退（现役）** | **0.8133** | **0.8379** | **0.8222** | **0.6515** |

- 对 v4b 回退版：总体 **+2.7pt**，B站 **+11.1pt**，三片全面占优（配对比较净胜、无任何回退片）；
- 置信回退整体增益：v5 总体 0.7576 → 0.8133（**+5.6pt**），B站 +13.3pt，正面召回不降。

### 2. 真实数据实测（两轮独立抽检，teacher 逐条复核）

| 抽检 | 构成 | 结果 |
|---|---|---|
| 第一次 400 条 | 博文100 / 评论100 / B站200 | B站按项目口径约 **92.5%**；博文官方内容 95%+ 高置信全对；评论非中性判定复核全对 |
| 第二次 200 条（全新样本） | B站100 / 博文50 / 评论50 | 总体 raw 0.81 / **回退后 0.85**（B站 0.84、博文 0.96、评论 0.76） |

- 两轮结论一致：模型行为与标注口径相符；
- 外部 agent 标注对照：与项目人工口径一致率 82%（agent 把玩梗/锐评大量误标负面，模型口径与金标一致而非与 agent 一致）。

### 3. 迭代过程沉淀的方法论资产
- 分片校验的标注工作流（id 集合 + 逐字节 text 一致性校验，零返工）；
- 三分片配额采样 + 负面先验约束（21–26%）的主动学习管线，含 35 个单元测试；
- 版本对比规范：三片准确率 + 配对差异 + 阈值扫描，杜绝小样本误判。

## 四、实验教训：v6 为什么没有晋级

用 LoL 赛事域新标 1000 条混训出 v6（6738 条），在 gold_eval_v4 上**全线低于 v5**（回退后总体 0.7756 vs 0.8097，配对净负 19），已否决。两个原因：

1. **域偏移**：新数据集中在 LoL 赛事内容，而评估金标是多游戏混合（异环 / 鸣潮等）。单游戏域内放量不会带来跨域提升，反而把 B站中性短句更多误判为正面；
2. **置信度上移，安全网失效**：数据变多后模型更自信，max_prob<0.75 的样本从 149 条降到 60 条，低置信回退这张核心保护垫大幅缩水，raw 错误更多直达输出。

> 结论：域内放量 ≠ 金标提升；下一轮候选池必须多游戏均衡采样。

## 五、已知短板（实测确认）

| 短板 | 实证 | 影响 |
|---|---|---|
| 直球加油/期待高置信漏判 | 「加油啊加油！！」conf 0.925 判中性、「西安曲江WE加油」0.931、「期待世一上首冠」0.946 | 正面召回损失，跨平台共性弱点 |
| 黑话反讽判成正面 | 「捞批捞实至名归」→正面 0.889、「缅北赛蛆太精彩了」→正面 0.959、「饼大哥定制冠军」→正面 0.781 | 负面漏判且置信极高，回退挡不住 |
| 回退牺牲负面召回 | 真实 200 条中负面召回 raw 11/20 → 回退后 6/20（30%） | 若业务以负面监测为核心需专门权衡 |
| weibo 评论片回退净负 | 50 条中翻错 4 条真负面、仅翻对 1 条 | 回退收益集中在 B站，非全片有效 |

## 六、后续改进方向

1. **多游戏均衡采样**（下一轮主动学习首选）：候选池覆盖多游戏而非 LoL 单域，直接针对 v6 失败教训；
2. **定向补样本**：直球应援/加油类正面样本（不限平台）+ 黑话反讽类负面样本（捞批捞/缅北/定制冠军型），这两类是目前高置信错误的主力；
3. **分片差异化回退阈值**：B站维持 0.75（收益大），weibo 评论考虑关闭或降低阈值——需在新的留出集上验证，避免在评估集上直接调参；
4. **回退阈值上调验证**：v5 在 T=0.85/0.90 上总体更高（0.8169/0.8241），但需新留出集确认后才能改部署；
5. **负面召回专项**：若舆情场景以负面监测为重点，评估「按片关回退 + 定向负面样本」组合；
6. 高置信错误只能靠扩样本解决，回退机制对 conf≥0.75 的错误无能为力（已多次实证）。
