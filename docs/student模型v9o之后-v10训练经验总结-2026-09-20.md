## 二、尺子踩坑（补飞书「v9o 假阳性」之后的落地）

### 坑：在坏尺子上继续训 = 在 1–3 条噪声上扫超参

gold_v6 B站片 n=390、中性 91.5%，「全判中性」acc=0.9154；v8 只比平庸基线多对 **1 条**。  
**B站 acc ≥ v8** 在结构上惩罚任何抬负召回的配方（假阳性砸在 357 条中性上）——所以闸门选出了负召回最差的 v9o。

### 修复：先修尺子，再谈训练（顺序不可换）

1. **扩样**：人工标 B站 iid 300（并入 gold→v7，1595 行）+ challenge 250（独立，不进 gold；负 69）。  
   - 富集**禁止用模型分数**（否则尺子偏袒旧模）。  
   - 抗议动员通道：人工负 28% vs v8 只判出 15% → 盲区定量坐实。
2. **闸门 `GATES_V7`**（`gold_gates.py` 唯一真源）：  
   - 微博评论 / 博文 acc ≥ v8；博文 negR ≥ 0.88  
   - B站：acc 降为护栏 **≥ v8−1.0pt**；主判据 = **challenge 负召回 ≥ v8**  
   - **i.i.d. 抽检升为晋级必过项**
3. **CLI**：`evaluate_gold_v7_gates.py`（双集合，FAIL 退出码 1）

**教训**：评估集分辨力不够时，任何「过闸」都可以是假阳性；矛盾时信 i.i.d.，不信坏片 acc。

## 三、存量重判踩坑：唯一 gold PASS 仍不能上线

16 个 v9 checkpoint 用新尺子重跑，比再训一轮便宜得多。

| 观察 | 含义 |
|---|---|
| **仅 v9k PASS** | challenge 只比 v8 多约 3 条（+4.3pt），没解决抗议盲区 |
| **v9o FAIL（chNR −7.2pt）** | 新尺子直接判决旧「PASS」 |
| **v9j 最接近** | chNR +17.4pt，B站护栏只差 **~0.45pt（约 3 条/689）** |
| **v9b 召回最猛** | chNR +26pt，护栏摔最重 → Pareto：negR↑ ↔ B站 acc↓ |

### v9k i.i.d.（2026-09-18）— FAIL

| 证据 | v8 | v9k |
|---|---|---|
| labeled300 总 acc | **0.8667** | 0.8600 |
| iid300 B站负召回 | **3/12** | 2/12 |
| iid2 487 分歧头对头 | **胜 9** | 胜 2 |
| 关键漏判 | — | 「比不过就是乐色」→中性 |

当日 StarRocks 微博池已空，新鲜段复用 iid2（无训练泄漏）。  
**教训：gold 闸门 PASS ≠ 可上线；i.i.d. 不过就维持现役。**

## 四、v10a/b 踩坑：杠杆切错轴

### 坑 1（v10a）：去重看起来「修数据」，实际拆掉护栏沙袋

`v7_1` 有 **569 行整行复制**（多来自 LoL B站中性闲聊 3×）。去重后 B站负面占比 19.6%→**26.1%**。

| | vs v9j（有复制对照） |
|---|---|
| challenge negR | 再 +1.4pt（约 1 条） |
| B站护栏 | **多摔 ~1.3pt** |
| 博文 | 刚过线 → 刚不过（−0.25pt） |

现役 v8 就是带复制训的——去重是待验证改动，不是免费午餐。

### 坑 2（v10b）：博文回放对症药开错

v10a 博文掉分触发「加博文回放」。结果：

- 博文 **仍 −0.25pt**（没拉回来）  
- challenge negR 冲到 **0.739**（接近 v9b）  
- B站护栏更差 **−4.1pt**

博文掉分不是「忘了博文」，而是负面敏感度整体上移的连带损伤；再堆回放只会沿「更负」方向滑。

### 明确不做（本轮实证）

- 再扫 LR / epoch（v9 已走完）  
- 再加更长/更强 B站或博文回放  
- 再摘某一整片训练数据「过闸」（v9o 覆辙）  
- 继续堆「去重 + 全量负面」

## 五、v9j 误差解剖：护栏税从哪来（设计链，不甩锅标注员）

相对 v8，v9j 在 gold B站片净少对 **10 条**（回归 19 / 改进 9），护栏差 ~3 条：

| 回归类型 | n | 实质 |
|---|---|---|
| 中性→正面 | **11** | round6「B站短应援/打 call=正面」vs 金标扩样「萌/惊艳」大量标中性 → **Teacher 与金标尺子打架** |
| 中性→负面 | **8** | 电竞闲聊/玩梗/交易黑话；challenge 用「举报/跑路/垃圾」捞负，训里缺同词中性对照 |

challenge：救回真负 +12，仍双漏 25（退游叙事、差点意思、陈述式问责）；新增 FP 14 脏在抗议词中性用法。

**三条设计链（代码改 LR/阈值解不了）：**

| 编号 | 链 | 后果 |
|---|---|---|
| A | Teacher 口径 ≠ 金标扩样口径（轻度夸） | 稳定交「中性→正面」税 |
| B | 抗议词表推召回，缺同词中性难例 | FP 负 + challenge 新 FP |
| C | v10 去重删 LoL 中性复制 | 拆的正是 B 的护栏沙袋 |

明细：`docs/v9j误差解剖-B站护栏-2026-09-18.md`、`data/validation/v9j_error_autopsy/`。

## 六、v10c 踩坑：中性校准方向对，剂量不够

配方：`v9_train_mixed`（8095）+ GLM 校准 219（中 161 / 负 43 / 正 15，重标后）→ `v10c_train_mixed` 8314；init=v8，5e-6×2ep。

| 闸门 | v10c | vs v8 | vs v9j |
|---|---|---|---|
| 评论 acc | 0.7584 | +1.8pt PASS | 略低 |
| 博文 acc | 0.8254 | −0.5pt FAIL | 更差 |
| 博文 negR | 0.906 | PASS | — |
| B站护栏 | **0.8708** | −1.45pt FAIL | **与 v9j 同值** |
| challenge negR | 0.580 | +11.6pt PASS | **低于 v9j 的 0.638** |

219 条难例没把 ~3 条护栏差额撬上来，还把 challenge 召回从 v9j 水平拉低。  
**教训：校准要够量、要对症（电竞闲聊 / 举报·跑路·垃圾中性用法 / 统一轻度夸口径）；「加一点中性」不等于护栏自动过线。**

校准说明书：`prompts/glm_teacher_shard_v10c.md`（加严：词面命中≠抗议；真退游/敷衍仍标负）。

## 七、工程纪律（本轮新增）

1. **闸门唯一真源**：只改 `gold_gates.py` + `tests/test_gold_gates.py`，禁止一次性脚本各写各的。  
2. **双集合评估**：iid/gold 管分布真实 acc；challenge 管负召回与精确率，**acc 不可与 iid 横比**。  
3. **富集金标不用模型分**：避免尺子偏袒。  
4. **i.i.d. 晋级必过**：gold PASS 只是入场券。  
5. **混训去重要当消融变量**：现役若在「有复制」分布上训出，去重会改变片内先验。  
6. **MPS 训练**：勿同时设 `PYTORCH_MPS_HIGH_WATERMARK_RATIO` env 与 `set_per_process_memory_fraction`；本机实测 fraction=0.0（不限）才能跑完。  
7. **权重不进 git**：`models/` gitignore；用 `share_student.py` 分发。

## 八、一句话结论（可贴飞书文首摘要）

> v9o 的 gold_v6 PASS 是坏尺子假阳性。修好 gold_v7 后：存量仅 v9k 过闸但 i.i.d. 否决；v10 去重/回放沿「更负」轴滑、护栏更摔；v10c 中性校准方向对但 219 条撬不动 ~3 条护栏。**现役维持 student_v8。** 下一刀仍是：统一轻度夸口径 + 加大中性难例校准（或扩 challenge），而不是再扫 LR / 再堆负面。
